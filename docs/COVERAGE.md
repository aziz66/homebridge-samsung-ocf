# HomeKit coverage (honest account)

Generated by test/coverage.gen.test.ts over the 141 captured fixtures.

**What this measures.** This plugin maps the subset of each Samsung appliance's
OCF resources that HomeKit can represent (temperature, humidity, power, doors,
fan speed, filter life, climate). HomeKit has no generic select/enum, duration,
or washer service, so capabilities like cycle/course selection, arbitrary mode
enums, stateless buttons, time-of-day and free-form status strings have no HomeKit
equivalent and are intentionally not exposed; some resources listed as unmapped
below (lights, some switches, PM density) are representable and are future work. The
reference localthings (Home Assistant) exposes far more because HA's entity
model is richer. The 'localthings entities' column is that reference count,
for context — it is NOT a target this plugin can reach on HomeKit.

**Reads replay real captures. Writes are modelled, not hardware-verified.**
